§01Overview and architecture

SPC Stream is a proposed cloud service that keeps control charts, run rules and capability current as readings arrive, routes alarms to Escalate, and exposes the same numbers to BI tools and customer agents. It is the concept successor to DataMyte's DataMetrics SPC software (see §12).

What it does

  • Ingests readings from gauges, PLC tags, Digital Clipboard checklists and legacy DataMetrics databases.
  • Runs Western Electric, EWMA and CUSUM rules per characteristic in real time.
  • Computes capability (Cp, Cpk, Pp, Ppk) and keeps a full history of limit changes.
  • Routes alarms to Escalate and can open a draft CAPA.
  • Serves charts and statistics to web, TV dashboards, Power BI and agents through one API.

Architecture

Data flows left to right. Every write passes schema validation at ingest, lands in the tenant data plane with an immutable audit entry, and is exposed to apps, BI and agents through the same API. Anything an agent proposes comes back as a draft that a named person approves.

§03Getting started

Proposed The quickest path from an empty tenant to a first live result.

Five steps

  1. Create a plant and a line in Admin → Plants.
  2. Add a characteristic: name, unit, spec limits, subgroup size and chart type.
  3. Connect a source: pair a Bluetooth gauge in Collect Edge, map an OPC UA node, or point a Digital Clipboard field at the characteristic.
  4. Collect at least 25 subgroups (or 100 individuals) and run Set limits; approve the phase I limits.
  5. Turn on rules (WE 1–4, EWMA, CUSUM) and choose who is notified.

First API call

Create a service client in Admin → Integrations, exchange its secret for a token, then call the API.

# 1. token (OAuth 2.0 client credentials)
curl -s -X POST https://auth.concept.example/oauth/token \
  -d grant_type=client_credentials -d client_id=$CLIENT_ID -d client_secret=$CLIENT_SECRET \
  -d scope="spc.read spc.write"
# 2. first call
curl -s https://acme.api.concept.example/v1/spc/characteristics?plant=plt_a -H "Authorization: Bearer $TOKEN"

§06REST API reference

Proposed REST over HTTPS, JSON bodies, base URL https://{tenant}.api.concept.example/v1. Every endpoint below is a design proposal; none is live.

Authentication

  • OAuth 2.0 client credentials for services; authorization code + PKCE for users; tokens are JWTs valid 15 minutes.
  • Scopes per product and verb: spc.read spc.write spc.approve. Plant-level claims restrict data to the plants granted.
  • Writes that change a released record (limits, plans, calibrations) require a user token and create a draft unless the user holds the approver role.

Draft and approval flow

  1. Agent calls a write tool; the server validates input and stores a draft with the evidence links.
  2. The owner gets a notification (Escalate, email or mobile push).
  3. A person with the approver role accepts, edits or rejects; acceptance applies the change and signs it (see §10).
  4. The agent receives the outcome by push notification or polling GET /drafts/{id}.

§08Statistics and methods

All figures in this section are Real dataset computed by chrismai.ai and match the Methods page. They are method demonstrations, not DataMyte or customer results.

Individuals and moving range (I-MR)

For one reading per time point, the short-term sigma comes from the average moving range of consecutive points:

MRt=|xt−xt−1|,σ^=MR¯d2,d2=1.128
UCL,LCL=x¯±3σ^=x¯±2.66MR¯

Worked example, UCI SECOM (McCann & Johnston, 2008; CC BY 4.0), signal #60 (column index 59; anonymized, no units). Phase I = first 500 lots: x̄ = 9.12, MR̄ = 11.35, σ̂ = 10.06, limits −21.06 to 39.31. On the 1,060 valid phase II lots the I chart flags 1 point.

EWMA

The exponentially weighted moving average reacts to small sustained shifts that a points-only chart misses.

zt=λxt+(1−λ)zt−1,z0=μ0
UCLt,LCLt=μ0±Lσλ2−λ[1−(1−λ)2t]

The steady-state limit drops the bracket. With λ = 0.2 and L = 3 the half-width is 3σ·√(0.2/1.8) = 1.000σ.

Worked example, SECOM signal #60: μ₀ = 9.12, σ = 10.06 (MR̄/1.128), steady-state limits 9.12 ± 10.06. Phase II alarms: 334 of 1,060 lots, first alarm at lot 503 — versus 1 on the I chart. The chart on the proposal recomputes this in your browser from the raw data file data/secom-s60.json.

// reference implementation (JavaScript), same as the live chart
function ewma(x, mu, sigma, lambda = 0.2, L = 3) {
  const half = L * sigma * Math.sqrt(lambda / (2 - lambda));
  let z = mu; const out = [];
  for (const v of x) { if (v == null) { out.push(null); continue; }
    z = lambda * v + (1 - lambda) * z;
    out.push({ z, alarm: Math.abs(z - mu) > half }); }
  return out;
}

CUSUM

Ct+=max(0,xt−(μ0+K)+Ct−1+),Ct−=max(0,(μ0−K)−xt+Ct−1−)

Default K = 0.5σ and H = 5σ (signal when C⁺ or C⁻ exceeds H), as configured on the screen's rules engine. Not run on SECOM in this concept.

X̄–R charts

X¯¯±A2R¯,UCLR=D4R¯,LCLR=D3R¯,σ^=R¯d2

Constants for n = 5: A₂ 0.577, D₃ 0, D₄ 2.114, d₂ 2.326.

Worked example, Montgomery piston rings via the qcc R package: inside diameter, 40 subgroups of 5 (mm); phase I = subgroups 1–25.

Capability: Cp, Cpk, Pp, Ppk

Cp=USL−LSL6σ^,Cpk=min(USL−X¯¯,X¯¯−LSL)3σ^

Pp and Ppk use the same formulas with the overall sample standard deviation s instead of σ̂ (long-term vs. short-term variation).

Piston rings, spec 73.95–74.05 mm (as in the qcc vignette), phase I: Cp 1.70, Cpk 1.66; Pp 1.66, Ppk 1.62. Reproduce in R: qcc(diameter[1:25,], type="xbar", newdata=diameter[26:40,]) and processCapability(q, spec.limits=c(73.95,74.05)).

§09Integrations

Proposed Integration points. Vendor names are typical targets, none confirmed as partners.

OPC UA

The edge gateway runs an OPC UA client (Security Policy Basic256Sha256, Sign&Encrypt). Subscriptions map node IDs to characteristics; sampling interval and deadband are set per node.

# gateway mapping (YAML)
- node: "ns=2;s=Line3.Press.Force"
  characteristic: chr_press_force
  sampling_ms: 500
  deadband: {type: absolute, value: 0.2}

MQTT (Sparkplug B)

Gateways publish to the tenant broker over TLS 8883. Topic namespace spBv1.0/{group}/DDATA/{edge_node}/{device}; birth/death certificates mark devices online and offline.

spBv1.0/plantA/DDATA/gw-line3/caliper-07
{"timestamp":1760796131000,"metrics":[{"name":"diameter","datatype":"Double","value":74.012}]}

MES / ERP

SAP, Plex and Epicor are typical targets (none confirmed). Outbound webhooks push events; inbound REST accepts part, order and serial context so every result carries genealogy.

Power BI and BI tools

DataMyte's DataMetrics page says it connects to Power BI today; the concept keeps that path. A read-only OData v4 feed (/v1/odata/spc) exposes curated tables with row-level security inherited from the user's token; scheduled refresh uses a service principal.

Data protection

  • Per-tenant schema plus PostgreSQL row-level security; plant claims in every token.
  • Encryption: TLS 1.2+ in transit; AES-256 at rest; customer-managed keys (KMS) on enterprise plans.
  • Backups: point-in-time recovery 35 days; encrypted, region-pinned.
  • Retention: configurable per record type; legal hold blocks deletion.

§12Migration from the legacy product

The legacy product, as DataMyte describes it

Cited DataMyte describes DataMetrics as SPC software with real-time data collection, process monitoring, reporting and traceability. Its modules include Insight (analysis), Online Reports, Setup Editor, Production Monitor and Active Directory security; it connects to Power BI, Quality Planning Studio and the DATAMYTE data collector, and describes "one central database". The page does not state a deployment model or system requirements. Sources: DataMetrics SPC software, On-Premise Hosting Agreement (pages read Oct 17, 2026).

Migration path

Proposed

  1. Install the bridge next to the existing DataMetrics database and sync read-only to a cloud tenant.
  2. Run both for one or two production months and compare limits and alarms.
  3. Move collection stations to stream mode plant by plant.
  4. Retire the local database, or keep it under an on-prem arrangement like DataMyte's On-Premise Hosting Agreement.

FAQ

Why EWMA as well as Shewhart?
On SECOM signal #60 the I chart flagged 1 of 1,060 phase II lots while EWMA flagged 334, starting at lot 503: small sustained shifts are invisible to points-only rules.

Can I keep DataMetrics?
Yes. The bridge syncs read-only until you decide to cut over.
