§01Overview and architecture

Torque Insight is a proposed service that turns every tightening and every residual audit into data. It learns an OK signature per joint, flags curves that deviate, trends reject rates by tool and workpiece, and proposes residual audit limits for an engineer to approve. It builds on DataMyte's LightStar wrench, Torque Expert and Revolution routes (see §12).

What it does

  • Collects final values and full curves from DC tool controllers and LightStar audits.
  • Learns OK envelopes per joint and scores each curve.
  • Trends NOK rates per joint, tool and workpiece with p-charts.
  • Proposes residual audit limits as drafts.
  • Opens audits and CAPA drafts through Escalate.

Architecture

Data flows left to right. Every write passes schema validation at ingest, lands in the tenant data plane with an immutable audit entry, and is exposed to apps, BI and agents through the same API. Anything an agent proposes comes back as a draft that a named person approves.

§03Getting started

Proposed The quickest path from an empty tenant to a first live result.

Five steps

  1. Register joints (ID, target torque, angle window, tool).
  2. Connect a tool controller through the gateway, or upload a CSV of runs.
  3. Mark a reference set of OK runs; train the envelope.
  4. Review flagged curves and tune thresholds per joint.
  5. Propose residual audit limits and approve them.

First API call

Create a service client in Admin → Integrations, exchange its secret for a token, then call the API.

# 1. token (OAuth 2.0 client credentials)
curl -s -X POST https://auth.concept.example/oauth/token \
  -d grant_type=client_credentials -d client_id=$CLIENT_ID -d client_secret=$CLIENT_SECRET \
  -d scope="torque.read torque.write"
# 2. first call
curl -s https://acme.api.concept.example/v1/torque/joints?plant=plt_a -H "Authorization: Bearer $TOKEN"

§06REST API reference

Proposed REST over HTTPS, JSON bodies, base URL https://{tenant}.api.concept.example/v1. Every endpoint below is a design proposal; none is live.

Authentication

  • OAuth 2.0 client credentials for services; authorization code + PKCE for users; tokens are JWTs valid 15 minutes.
  • Scopes per product and verb: torque.read torque.write torque.approve. Plant-level claims restrict data to the plants granted.
  • Writes that change a released record (limits, plans, calibrations) require a user token and create a draft unless the user holds the approver role.

Draft and approval flow

  1. Agent calls a write tool; the server validates input and stores a draft with the evidence links.
  2. The owner gets a notification (Escalate, email or mobile push).
  3. A person with the approver role accepts, edits or rejects; acceptance applies the change and signs it (see §10).
  4. The agent receives the outcome by push notification or polling GET /drafts/{id}.

§08Statistics and methods

Figures are Real dataset from PyScrew s01 (West & Deuse, TU Dortmund; CC BY 4.0): 5,000 tightening runs on 100 workpieces, target 1.4 Nm, recorded at 833 Hz on an automatic screwing station. This is installation torque, not residual audit torque.

Curve preprocessing

Each run is a torque–angle series τ(θ). Curves are aligned at the seating point and resampled onto a common angle grid θ₁…θm. Seating is detected where the torque gradient first exceeds a threshold:

θseat=min{θ:dτdθ>g}

OK envelope and residuals

From a reference set of OK curves (first-use threads), compute the pointwise mean and standard deviation, then score each new curve by its standardized residuals:

μ(θj)=1N∑i=1Nτi(θj),rj=τ(θj)−μ(θj)s(θj)
Dmax=maxj|rj|,Drms=1m∑jrj2

A curve is flagged when Dmax exceeds an envelope threshold (default 4) or Drms exceeds a learned 99.5th percentile. Flags carry the angle window where the deviation occurs, which separates early cross-threading from late stripping. These thresholds are proposed defaults and need validation per joint.

What the PyScrew data shows

StatisticValue
Runs / workpieces5,000 / 100
Not OK911 of 5,000 (18.2%)
NOK at first use → 25th use of the thread0% → 41%
Final torque, completed runs1.421 Nm mean, SD 0.038 (n 4,151)

NOK rises with thread reuse (thread wear), which is visible in curve shape before the final torque value changes much — the reason to score whole curves, not just the end point.

Proposing residual audit limits

Torque Expert (as DataMyte describes it) covers residual limits calculation. Torque Insight proposes limits for an engineer to approve:

Llo,hi=τ¯±3s

Method illustration on the PyScrew installation data: 1.421 ± 3 × 0.038 = 1.307 to 1.535 Nm. Residual (breakaway or angle-restart) torque differs from installation torque, so real limits must come from residual audits on the same joint; this example only shows the arithmetic.

Reject-rate trend

p^k=NOKknk,UCL=p¯+3p¯(1−p¯)nk

A p-chart per joint and tool (200 runs per reuse count in the dataset) alerts before the reject rate climbs.

§09Integrations

Proposed Integration points. Vendor names are typical targets, none confirmed as partners.

OPC UA

The edge gateway runs an OPC UA client (Security Policy Basic256Sha256, Sign&Encrypt). Subscriptions map node IDs to characteristics; sampling interval and deadband are set per node.

# tool controller result node (vendor-specific node IDs vary)
- node: "ns=4;s=Controller07.LastResult"
  joint: jnt_tq20
  fields: [final_nm, final_deg, result, curve_ref]

MQTT (Sparkplug B)

Gateways publish to the tenant broker over TLS 8883. Topic namespace spBv1.0/{group}/DDATA/{edge_node}/{device}; birth/death certificates mark devices online and offline.

spBv1.0/plantA/DDATA/gw-line3/dc-tool-07
{"timestamp":1760806931000,"metrics":[{"name":"final_nm","datatype":"Double","value":1.42},{"name":"result","datatype":"String","value":"OK"}]}

MES / ERP

MES supplies serial/VIN genealogy for each run. Outbound webhooks push events; inbound REST accepts part, order and serial context so every result carries genealogy.

Power BI and BI tools

Joint, run and audit tables are available to BI. A read-only OData v4 feed (/v1/odata/torque) exposes curated tables with row-level security inherited from the user's token; scheduled refresh uses a service principal.

Data protection

  • Per-tenant schema plus PostgreSQL row-level security; plant claims in every token.
  • Encryption: TLS 1.2+ in transit; AES-256 at rest; customer-managed keys (KMS) on enterprise plans.
  • Backups: point-in-time recovery 35 days; encrypted, region-pinned.
  • Retention: configurable per record type; legal hold blocks deletion.

§12Migration from the legacy product

Proposed

FAQ

Why curves and not just final torque?
In the PyScrew data, NOK rises from 0% to 41% with thread reuse; curve shape shows wear before the final value moves much.

Is installation torque the same as residual torque?
No. Residual torque is measured after tightening (breakaway or angle-restart) and is typically different.

Is this DataMyte software?
No. It is an unsolicited concept by chrismai.ai, not affiliated with or endorsed by DataMyte.

Is the manual available in other languages?
English only for now. Translation into the same 13 languages as the app user manuals is available on request.
