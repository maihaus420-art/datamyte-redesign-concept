Digital Clipboard コンセプトマニュアル：自動車品質ワークフロー

このマニュアルは chrismai.ai が作成したコンセプト画面を説明するもので、DataMyte の公式ドキュメントではありません。画面とデータはすべてサンプルです。

機械支援翻訳です。使用前にネイティブスピーカーによる確認が必要です。 (Machine-assisted translation; needs native-speaker review. Screen UI shown in English.)

  2. チェックリストの作成

1. はじめに

  1. サインインし、上部バーで工場とラインを選択します。
  2. 4つのタイル（直行率、未解決の問題、本日の検査数、検査漏れ）を確認します。
  3. エスカレーションまたは是正処置をクリックすると詳細が表示されます。

2. チェックリストの作成

  1. Workflow Builder を開き、空のフォームまたはテンプレートライブラリから始めます。
  2. バーコード、写真、署名などのデータ要素をフォームにドラッグします。
  3. トルク検査では、ワイヤレストルクレンチ要素を追加し、基準値と上下限値を設定します。
  4. 「規格外の場合」で写真を必須にし、エスカレーションプランを選択します。
  5. プレビューをクリックし、ラインのタブレットにフォームを公開します。

3. 検査の実施

  1. タブレットで部品のバーコードをスキャンします。
  2. 各締結部を締め付けます。測定値はワイヤレスレンチから送られ、合格または不合格が表示されます。
  3. 不合格の場合は、必要な写真を撮影してメモを追加します。
  4. 署名して「検査を送信」をタップします。

4. エスカレーション

  1. 測定値が規格外になると、班長に端末通知とメールが届きます。
  2. 班長は「確認」をタップし、封じ込め作業を完了します。
  3. 期限内に問題がクローズされない場合、自動的に次のレベルへエスカレーションされます。

5. 是正処置（CAPA）

  1. エスカレーションから「CAPA を開く」をクリックします。検査記録と写真が添付されます。
  2. D1〜D8 の各段階（チーム、問題、封じ込め、根本原因、是正処置、検証、再発防止、完了）を進めます。
  3. 担当者と期限を設定してタスクを割り当て、作業が終わったら段階を更新します。

6. レポートと SPC

  1. SPC Analytics を開くと、特性の管理図、管理限界、Cpk を確認できます。
  2. 管理限界外の赤い点は、対応するエスカレーションにリンクしています。
  3. レポートでシリアル番号を検索すると、トレーサビリティ履歴をすべて確認できます（図 8）。
  4. Excel、CSV、Power BI、または PDF 監査パックにエクスポートできます。

7. AI 機能

  1. CONVERT-ai：紙のフォームの PDF、スプレッドシート、テキストファイルをアップロードします。生成されたワークフローを確認・編集してから公開します。
  2. COMPOSE-ai：チェックリストを普段の言葉で説明します。一文でフィードバックすると新しいバージョンが作成され、最終プレビューで確定します。

8. 管理

  1. 工場ごとにユーザーの役割と権限を設定します。
  2. 作業者が使用できる言語を選択します。
  3. 監査の前に変更履歴を確認します。
