Digital Clipboard 콘셉트 매뉴얼: 자동차 품질 워크플로

이 매뉴얼은 chrismai.ai가 만든 콘셉트 화면을 설명하며, DataMyte의 공식 문서가 아닙니다. 모든 화면과 데이터는 샘플입니다.

기계 지원 번역입니다. 사용 전 원어민 검토가 필요합니다. (Machine-assisted translation; needs native-speaker review. Screen UI shown in English.)

  1. 시작하기
  2. 체크리스트 만들기
  3. 검사 수행
  4. 에스컬레이션
  5. 시정 조치(CAPA)
  6. 보고서와 SPC
  7. AI 기능
  8. 관리

1. 시작하기

  1. 로그인한 후 상단 바에서 공장과 라인을 선택합니다.
  2. 네 개의 타일(초도 합격률, 미해결 이슈, 오늘 검사 수, 누락된 검사)을 확인합니다.
  3. 에스컬레이션이나 시정 조치를 클릭하면 세부 정보가 열립니다.

2. 체크리스트 만들기

  1. Workflow Builder를 열고 빈 양식이나 템플릿 라이브러리에서 시작합니다.
  2. 바코드, 사진, 서명 같은 데이터 요소를 양식으로 끌어다 놓습니다.
  3. 토크 검사에는 무선 토크 렌치 요소를 추가하고 기준값과 상한·하한을 설정합니다.
  4. "규격 이탈 시"에서 사진을 필수로 지정하고 에스컬레이션 계획을 선택합니다.
  5. 미리 보기를 클릭한 다음 라인의 태블릿에 양식을 게시합니다.

3. 검사 수행

  1. 태블릿에서 부품 바코드를 스캔합니다.
  2. 각 체결부를 조입니다. 측정값이 무선 렌치에서 전송되며 합격 또는 불합격으로 표시됩니다.
  3. 측정값이 불합격이면 필요한 사진을 찍고 메모를 추가합니다.
  4. 서명한 후 검사 제출을 누릅니다.

4. 에스컬레이션

  1. 측정값이 규격을 벗어나면 감독자가 기기 알림과 이메일을 받습니다.
  2. 감독자는 확인을 누르고 봉쇄 작업을 완료합니다.
  3. 정해진 시간 안에 이슈가 종결되지 않으면 자동으로 다음 단계로 에스컬레이션됩니다.

5. 시정 조치(CAPA)

  1. 에스컬레이션에서 CAPA 열기를 클릭합니다. 검사 기록과 사진이 첨부됩니다.
  2. D1~D8 단계(팀, 문제, 봉쇄, 근본 원인, 시정 조치, 검증, 재발 방지, 종결)를 진행합니다.
  3. 담당자와 기한을 정해 작업을 배정하고, 작업이 끝나면 단계를 업데이트합니다.

6. 보고서와 SPC

  1. SPC Analytics를 열어 특성의 관리도, 관리 한계, Cpk를 확인합니다.
  2. 관리 한계를 벗어난 빨간 점은 해당 에스컬레이션으로 연결됩니다.
  3. 보고서에서 일련번호를 검색하면 전체 추적 이력을 볼 수 있습니다(그림 8).
  4. Excel, CSV, Power BI 또는 PDF 감사 패키지로 내보냅니다.

7. AI 기능

  1. CONVERT-ai: 종이 양식의 PDF, 스프레드시트 또는 텍스트 파일을 업로드합니다. 생성된 워크플로를 검토하고 수정한 후 게시합니다.
  2. COMPOSE-ai: 체크리스트를 쉬운 말로 설명합니다. 한 문장으로 피드백하면 새 버전이 만들어지고, 최종 미리 보기에서 확정합니다.

8. 관리

  1. 공장별로 사용자 역할과 권한을 설정합니다.
  2. 작업자가 사용할 수 있는 언어를 선택합니다.
  3. 감사 전에 변경 이력을 검토합니다.
