Digital Clipboard 概念手册：汽车质量工作流程

本手册介绍由 chrismai.ai 制作的概念界面，并非 DataMyte 官方文档。所有界面和数据均为示例。

1. 入门

  1. 登录后，在顶部栏选择工厂和产线。
  2. 查看四个指标卡：一次合格率、未结问题、今日检验数和漏检数。
  3. 点击任一升级事件或纠正措施即可查看详情。

2. 创建检查表

  1. 打开 Workflow Builder，从空白表单或模板库开始。
  2. 将条形码、照片或签名等数据元素拖到表单上。
  3. 对于扭矩检查，添加无线扭矩扳手元素，并设置名义值及上下限。
  4. 在“超出规格时”中，要求拍照并选择升级方案。
  5. 点击预览，然后将表单发布到该产线的平板电脑。

3. 执行检验

  1. 在平板电脑上扫描零件条形码。
  2. 拧紧每个紧固件。读数从无线扳手传入，并显示“合格”或“不合格”。
  3. 如果读数不合格，请拍摄要求的照片并添加备注。
  4. 签名后点击“提交检验”。

4. 升级处理

  1. 读数超出规格时，主管会收到设备通知和电子邮件。
  2. 主管点击“确认”并完成遏制任务。
  3. 如果问题未在规定时间内关闭，将自动升级到下一级。

5. 纠正措施（CAPA）

  1. 在升级事件中点击“打开 CAPA”，检验记录和照片会自动附上。
  2. 依次完成 D1 至 D8：团队、问题描述、遏制、根本原因、纠正措施、验证、预防和关闭。
  3. 为任务指定负责人和截止日期，并在完成后更新阶段。

6. 报告与 SPC

  1. 打开 SPC Analytics，查看某一特性的控制图、控制限和 Cpk。
  2. 超出控制限的红点会链接到对应的升级事件。
  3. 在“报告”中搜索序列号，即可查看完整的追溯记录（图 8）。
  4. 可导出为 Excel、CSV、Power BI 或 PDF 审核包。

7. AI 功能

  1. CONVERT-ai：上传纸质表单的 PDF、电子表格或文本文件。发布前请审核并编辑生成的工作流程。
  2. COMPOSE-ai：用日常语言描述检查表。用一句话提出修改意见即可生成新版本，然后在最终预览中确认。

8. 管理

  1. 为每个工厂设置用户角色和权限。
  2. 选择操作员可用的语言。
  3. 审核前检查变更历史。
