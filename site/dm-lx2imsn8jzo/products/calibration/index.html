Product suite / Gage Cloud

Gage Cloud

Calibration management with IoT gauge tracking. Concept, not DataMyte's actual software.

Open the live concept screen. The screen's bias study uses real NIST data: five 4-point probes on five silicon wafers over six days (NIST/SEMATECH e-Handbook §2.6.1).

Today (DataMyte's pages)

  • EnGagePlus! gauge tracking software

EnGagePlus! is described as gauge and tool automation software: calibration records and history, tool-crib check-in/out, reports for due, overdue and out-of-tolerance gauges, certificates and location, and built-in Gauge R&R (standard or ANOVA), bias, stability and linearity studies.

Current form: The page does not state a deployment model or system requirements.

New-era SaaS concept Illustrative

A cloud gauge registry where every caliper, torque tool and probe has a live record. BLE tags on tool cases update “last seen”, calibration due dates feed work orders, and Digital Clipboard blocks a reading from an overdue gauge. Studies run on collected data, and certificates are stored with each event.

Cloud multi-tenant architecture

Sketch, not a built system. Tenant isolation by schema plus row-level security; regional data residency; customer-managed keys for enterprise tenants. Illustrative

Pricing ideas Idea

  • Per tracked gauge, in tiers.
  • IoT tags per tag per month, with gateways sold separately.
  • Studies included; external lab portal seats free.

Ideas for discussion, not offers or DataMyte prices. The only real price referenced is DataMyte's public seat price.

API, agent and MCP hooks

REST and webhooks for everything in the UI, an A2A agent card for discovery, and an MCP server with scoped tools. Anything that changes a record comes back as a draft for a person to approve.

  • gage.get(id)
  • gage.list_due(days)
  • gage.schedule_calibration(id, date) → draft
  • gage.record_study(id, type, data)

AI features

  • Predict drift from past calibration results
  • Flag gauges used while overdue
  • Summarize a study for an auditor

Mobile and offline

Crib check-in/out by phone scan; lab results captured offline.

Integrations

Calibration lab systems by CSV/API, ERP for asset numbers, Digital Clipboard for in-use checks.

Migration path for on-prem customers

  1. Export EnGagePlus! gauge records and history.
  2. Import into the registry and reconcile IDs.
  3. Tag the highest-risk tools first (torque wrenches, master gauges).
  4. Switch scheduling and certificates to the cloud.
