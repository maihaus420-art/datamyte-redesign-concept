Torque Insight

Connected torque analytics. Concept, not DataMyte's actual software.

Open the live concept screen. The screen uses real torque–angle data: PyScrew s01 (West & Deuse, TU Dortmund, CC BY 4.0), 5,000 tightening runs. It is installation data from an automatic screwing station, not residual audit torque.

Today (DataMyte's pages)

  • LightStar residual torque wrench
  • Torque Expert
  • Revolution PRO

LightStar is a wireless residual torque wrench using a patented angle-restart method, with breakaway, loosening, angle breakaway, peak and set modes, tool ID and calibration tracking. The page offers a buyback for older Digital DSL and Analog LSU wrenches. Torque Expert covers torque studies, audit data collection, residual limits calculation and Escalate reporting, and Revolution guides LightStar through audit routes.

Current form: Hardware (wrench and Revolution collector) plus software; the pages do not state a deployment model.

New-era SaaS concept Illustrative

Every tightening and every residual audit becomes data: final values plus full torque–angle curves. The service learns an OK signature per joint, flags curves that deviate, trends reject rates by tool and workpiece, and proposes residual audit limits from installation data for an engineer to approve.

Cloud multi-tenant architecture

Sketch, not a built system. Tenant isolation by schema plus row-level security; regional data residency; customer-managed keys for enterprise tenants. Illustrative

Ideas for discussion, not offers or DataMyte prices. The only real price referenced is DataMyte's public seat price.

API, agent and MCP hooks

REST and webhooks for everything in the UI, an A2A agent card for discovery, and an MCP server with scoped tools. Anything that changes a record comes back as a draft for a person to approve.

  • torque.get_joint_stats(joint, range)
  • torque.get_curve(run_id)
  • torque.propose_limits(joint) → draft
  • torque.open_audit(joint, reason)

AI features

  • Curve anomaly detection against the learned OK envelope
  • Root-cause hints: thread wear, cross-thread, missing washer
  • Predict reject-rate rise before it happens

Mobile and offline

Audit routes run offline on Revolution or phones; results sync with curves.

Integrations

Tool controllers over OPC UA or vendor protocols, MQTT for line events, MES for serial/VIN genealogy.

Migration path for on-prem customers

  1. Keep existing LightStar wrenches and Revolution routes.
  2. Add the cloud connector so audit results and curves upload.
  3. Connect assembly-line DC tools for installation data.
  4. Use proposed limits once engineers approve them.
